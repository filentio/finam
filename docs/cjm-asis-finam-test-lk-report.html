Проблемы (структурировано)

Навигация/термины UX средний

Неочевидно, что это “ещё один счёт”

  • На дашборде CTA “Открыть новый счёт” можно трактовать как “первый/новый профиль”.
  • Рекомендация: переименовать в “Открыть ещё один счёт” и добавить пояснение “в рамках текущего профиля/договора”.
Выбор сервисов UX средний

QUIK/TRANSAQ без рекомендаций и без наследования

  • Пользователь не понимает, что выбрать и чем отличается.
  • Для 2+ счёта логично предзаполнять “как в предыдущем счёте”.
Документы/подпись Trust высокий

Большой пакет документов (6) без summary

  • Низкая прозрачность: “что подписываю и зачем?”.
  • Рекомендация: краткое резюме + “скачать всё” + “что изменится после подписи”.
Статусы и результат Status высокий

После подписи нет ясного “готово/не готово”

  • Статусы “создается” и “получено системой ЭДО” могут путать.
  • В журнале есть “(Комментарий)” для ошибок, но без причины и без кнопки “исправить”.
  • Рекомендация: финальный экран результата + раскрытие причины отказа + CTA “исправить и повторить”.

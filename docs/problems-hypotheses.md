# Проблемы (гипотезы) в онбординге открытия счёта — чеклист

Этот список помогает быстро “пройтись” по продукту и найти типовые точки потерь.
Заполняйте фактами из скринкаста/HAR/обращений в поддержку.

## A. Вход / регистрация

- **OTP не приходит / задерживается**  
  Симптом: повторные запросы кода, уход пользователя.  
  Проверить: latency SMS/email, rate limits, тексты ошибок, антифрод.

- **Дубликаты аккаунтов / неясное восстановление**  
  Симптом: пользователь повторно регистрируется, теряет прогресс.  
  Проверить: сценарии “уже клиент” vs “новый”.

- **Неясные требования к паролю / 2FA**  
  Симптом: циклы ошибок на форме.  
  Проверить: правила, подсказки, ошибки “почему”.

## B. Выбор счёта/тарифа

- **Неясно какой продукт выбрать**  
  Симптом: остановка на выборе, возврат назад.  
  Проверить: сравнение тарифов, калькулятор, рекомендации по профилю.

- **Скрытые условия**  
  Симптом: “узнал на середине”, откат/отказ.  
  Проверить: требования к документам, ограничения по резидентству.

## C. Анкета KYC/AML

- **Слишком много полей на старте**  
  Симптом: усталость, drop-off.  
  Проверить: можно ли отложить часть данных на “после открытия”.

- **Ошибки только на финале**  
  Симптом: “потратил 10 минут и всё пропало”.  
  Проверить: валидации на каждом поле, подсветка конкретного поля.

- **Непонятные формулировки**  
  Симптом: ошибки выбора, обращение в поддержку.  
  Проверить: подсказки “зачем спрашиваем”, примеры ответов.

## D. Документы / селфи

- **Отклонения без причины**  
  Симптом: повторные попытки, уход.  
  Проверить: причины отклонения и тексты, рекомендации, предпросмотр качества.

- **Технические сбои камеры/разрешений**  
  Симптом: не может загрузить.  
  Проверить: fallback “загрузить файл”, инструкции, совместимость браузеров.

## E. Договоры / согласия / подпись

- **Длинные документы без резюме**  
  Симптом: “галочки” без понимания, недоверие.  
  Проверить: summary + ссылки, что обязательно/опционально.

- **Сбой подписи без пути восстановления**  
  Симптом: тупик.  
  Проверить: повторить подпись, сменить способ, сохранить черновик.

## F. Проверка / статусы

- **Непрозрачный SLA**  
  Симптом: рост обращений “что со мной?”.  
  Проверить: статус-страница, уведомления, точные сроки.

- **“Нужны данные” без точной инструкции**  
  Симптом: повторные ошибки.  
  Проверить: подсветка именно того поля/файла, который нужен.

## G. First value

- **Счёт открыт, но действия недоступны**  
  Симптом: “почему нельзя пополнить/торговать?”.  
  Проверить: явные требования, next best action, объяснение ограничений.

## Что нужно, чтобы превратить гипотезы в факты

- скринкаст 5–15 минут полного прохождения
- HAR-файл с сетевыми запросами
- тексты ошибок (дословно)
- время на шаги + где “зависает”

## Наблюдения по скринам (Finam test-lk): что уже подтверждено

- **Лоадер без ETA**: есть экран “Формируются документы для подписания” без времени ожидания и без действий.
- **Большой пакет документов на подпись**: на экране “Документы на подпись” формируется **6 документов** без краткого резюме.
- **Неочевидная развилка “Подписать” vs “Завершить”**: на экране документов присутствуют обе кнопки; без дополнительного контекста это создаёт риск выхода до завершения подписи.
- **Статусы могут быть непонятны**: встречается “Единый счёт — создается” и “получено системой ЭДО” — неочевидно, равняется ли это “счёт открыт”.
- **Журнал заявок показывает ошибки с “Комментарий”**: в списке заявок есть красные статусы с пометкой “(Комментарий)”, но без раскрытия причины на этом экране.

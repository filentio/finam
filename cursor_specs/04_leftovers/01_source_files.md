## 4) Остатки / исходники

Этот раздел хранит источники, которые используются как основание, но не являются “спецификацией” сами по себе.

### Исходники из выгрузки Manus
- `cursor_specs/assets/source/presentation_vertical_slides.json` — HTML-слайды (38 экранов), outline, ссылки на скриншоты.
- `cursor_specs/assets/source/slide_texts.json` — извлечённый точный текст по каждому `slide_id`.
- `cursor_specs/assets/source/structure_and_cta.md` — исходная схема структуры и CTA (использована для построения канонического порядка).
- `cursor_specs/assets/source/audit_report.md` — аудит полноты (исторически; фиксирует недостающие экраны, которые уже добавлены в финальную колоду).
- `cursor_specs/assets/source/slide_notes.md` — заметки спикера (исторический артефакт; не покрывает все 38 экранов).
- `cursor_specs/assets/source/structure_and_cta.pdf`, `structure_and_cta(1).pdf` — PDF версии схемы.
- `cursor_specs/assets/source/visual_user_flow.png` — визуальный user flow с миниатюрами (референс).
- `cursor_specs/assets/source/Лид-магнитдляновичковЖариков(2).pptx` — исходная презентация пользователя.
